# 업무 자동 분류 대시보드

3인 규모 스타트업에서 한 사람이 하루에 5~7개 직무를 오가는 상황을 전제로 만든
프로토타입. 이메일·디스코드로 흩어져 들어오는 비정형 텍스트에서 할일을 자동
추출해 **직무별로 분류·우선순위화**하고 한 화면에 모은다.

## 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 를 채우면 실제 추출
npm run dev                  # http://localhost:3000
```

키가 없어도 그대로 실행된다. 아래 "데모 모드" 참고.

## 핵심 플로우

1. 왼쪽 패널에 원문을 붙여넣거나 샘플 버튼으로 주입
2. **AI로 할일 추출하기** → `/api/extract` → Claude(`claude-sonnet-5`)가 JSON 배열 반환
3. 오른쪽에 할일 카드 (제목 / 직무 / 우선순위 / 마감 / 담당자 / 근거 한 줄)
4. 카드 클릭 → 왼쪽 원문에서 그 근거 문장이 노란색으로 하이라이트
5. 카드 위에서 **우선순위·담당자를 사람이 직접 바꾼다**
6. 아래 직무별 칸반에서 카드를 끌어 상태 변경. **다른 직무 레인에 놓으면 직무도 함께 바뀐다**

## AI가 정한 값을 사람이 덮어쓰는 경로

이 프로토타입의 전제는 "AI 분류를 100% 믿지 않아도 된다"이다.
추출된 네 가지 값 모두 사람이 고칠 수 있어야 그 전제가 성립한다.

| 값 | 사람이 고치는 방법 |
|---|---|
| 직무 | 칸반에서 다른 직무 레인으로 드래그 |
| 상태 | 칸반에서 다른 컬럼으로 드래그 |
| 우선순위 | 카드의 우선순위 배지 (드롭다운) |
| 담당자 | 카드의 담당자 배지 (드롭다운, 명단은 `lib/team.ts`) |

담당자가 `미지정`인 카드는 배지가 주황색으로 뜨고, 상단 요약에
**담당자 미지정** 건수가 집계된다. 3인 팀에서 "이건 누가 하나"가
비어 있는 것 자체가 처리해야 할 신호이기 때문이다.

원문에서 유추한 이름이 팀 명단에 없는 경우(예: 고객사 담당자)에도
그 값이 선택지에서 사라지지 않는다.

추출 결과는 누적된다. 세 샘플을 차례로 넣으면 여러 채널의 할일이 한 보드에 모인다.

## 데모 모드

`ANTHROPIC_API_KEY`가 없거나 API 호출이 실패하면 **500을 내지 않고** 미리 정의한
결과로 폴백하고 화면 상단에 `데모 모드` 뱃지를 띄운다. 뱃지에 마우스를 올리면
폴백 사유가 보인다. 시연 중 빈 화면이 나오지 않는 것이 이 프로토타입의 요구사항이다.

- 샘플 3종 → 각각에 대응하는 프리셋 결과 (`lib/samples.ts`)
- 임의의 텍스트 → 원문 기반 최소 추출기 (`lib/demo.ts`). 정확도가 아니라
  "무언가는 반드시 나온다"가 목적

프리셋 마감일은 절대 날짜로 굳혀두지 않았다. 원문의 "이번 주 금요일", "다음 주 초"와
결과가 항상 맞도록 시연 당일 기준으로 계산한다(`PresetDue`). 언제 열어도 날짜가 어긋나지 않는다.

## 중복 처리

디스코드 샘플의 "다온컴퍼니 녹음 잘림" 건은 CS 메일 건과 같은 일이다.
같은 일이 여러 채널로 중복 인입되는 것이 이 문제의 핵심이라 **자동 병합하지 않고
`중복 의심` 뱃지만 붙여** 사람이 판단하게 둔다.

비교는 글자 2-gram 포함도(`lib/dedupe.ts`)로 한다. 한국어는 조사·어미가 흔들려서
("재현하기" vs "재현하고") 단어 단위 비교가 잘 깨진다. 실제 프리셋에서 의도한
중복 쌍은 0.57, 나머지 모든 쌍은 0.13 이하로 임계값 0.5와 간격이 넉넉하다.

## 구조

```
app/
  page.tsx              유일한 상태 소유자 (로컬 state, DB 없음)
  api/extract/route.ts  Anthropic 호출 + 데모 폴백
lib/
  types.ts    도메인 타입 (직무 9종 / 우선순위 / 상태)
  roles.ts    직무별 배지 색 — Tailwind JIT 때문에 클래스 문자열을 정적으로 보관
  dates.ts    KST 기준 오늘, 상대 요일 계산
  samples.ts  샘플 원문 3종 + 데모 프리셋
  prompt.ts   시스템/유저 프롬프트 (오늘 날짜 주입)
  parse.ts    모델 출력 방어적 파싱 (코드펜스·잡텍스트·표기 흔들림 흡수)
  dedupe.ts   중복 판정
  demo.ts     임의 텍스트용 최소 추출기
  team.ts     3인 팀 명단 (담당자 드롭다운 선택지)
components/
  SourcePanel / TaskList / TaskCard / SummaryStrip / KanbanBoard
  Badge / BadgeSelect (배지처럼 보이는 드롭다운)
```

드래그는 라이브러리 없이 HTML5 `draggable`을 쓴다. 시연에서 의존성을 하나라도 줄이려는 선택.

## 프롬프트에서 신경 쓴 것

- JSON 배열 외 출력 금지 (설명·마크다운 코드펜스 금지)
- 상대 날짜를 **오늘 날짜를 주입해** 실제 `YYYY-MM-DD`로 변환시킴
- `source`는 원문 문장을 글자 그대로 복사하도록 강제 — 하이라이트가 여기에 걸리고,
  근거를 지어내지 못하게 하는 장치이기도 하다
- 상황 공유·인사말은 할일이 아니라고 명시

모델이 규칙을 어겨도 `lib/parse.ts`가 흡수하고, 그마저 실패하면 데모 모드로 떨어진다.

## 검증한 것

- `npm run build` 통과
- 샘플 3종 추출 → 카드 10개, 중복 1건 표시, 요약 스트립 집계 일치
- **10개 카드 전부** 클릭 시 원문에서 근거 문장 하이라이트 성공
- 드래그로 상태 변경 / 다른 직무 레인 이동 시 직무 변경 동작
- 우선순위·담당자 드롭다운 변경이 카드·칸반·요약 집계에 모두 반영
- 드롭다운을 조작해도 카드 선택(하이라이트)이 오작동하지 않음
- 팀 명단에 없는 담당자 이름도 선택지에 유지
- 임의 텍스트 데모 폴백: 상대 날짜("내일", "이번 주 금요일") 변환과 직무 추정 동작,
  할일 아닌 문장은 제외
- 파서: 코드펜스, 앞뒤 설명, 문자열 안 대괄호, 표기 흔들림, JSON 아닌 응답 처리
- 빈 본문 / 잘못된 JSON 요청 → 400
- 1440px·900px 폭에서 가로 스크롤 없음

실제 Anthropic API 호출 경로는 이 환경에 자격 증명이 없어 **실측하지 못했다.**
키를 넣고 한 번 확인이 필요하다.

## 범위 밖

DB·인증·다중 사용자·실제 메일/디스코드 연동은 넣지 않았다. 상태는 새로고침하면 사라진다.
